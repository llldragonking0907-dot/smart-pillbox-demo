# 智能药箱产品设计说明

## 一、场景选择
选择场景B：异地子女 × 父母药箱
选择该场景是源于真实个人需求：我的父母均 67 岁，父亲患有高血压、母亲患有心脏瓣膜疾病，需长期规律服药，两位老人不擅长智能设备操作；我长期在外地上学，本身就面临无法当面确认父母按时服药的异地看护痛点，因此选择该场景设计第一版方案。

## 二、核心用户
1. **第一用户**：异地居住、可熟练使用智能手机的成年子女，为产品购买者、系统管理者，负责用药计划录入与异常处理
2. **第二用户**：不擅长智能设备操作的独居父母，为硬件实际使用者，仅需完成取药动作，无需面对复杂的智能设备。

## 三、核心问题
父母是否按时按量取药、子女能否及时获取真实服药反馈。解决异地用药信息不对称问题，确保子女能及时掌握父母服药过程中的异常状况。

## 四、核心业务流程
1. **计划录入**：子女在App端通过自然语言描述/上传药品图片，系统解析生成结构化用药计划，子女核对确认后下发至药箱
2. **本地提醒**：到达服药时间，药箱按顺序逐仓点亮指示灯，同步进行大音量语音播报，告知药仓序号、药品名称、剂量、服用要求
3. **取药判定**：重量传感器检测药仓重量变化，符合正常取药重量区间则判定取药完成；检测到重量回弹则判定为误碰，继续等待取药
4. **反馈同步**：正常取药后，App向子女推送服药完成记录；超时未取、重量异常时，App向子女推送告警信息
5. **周期总结**：每周自动汇总服药数据，生成趋势总结

## 五、AI能力体现
大语言模型能力贯穿输入、校验、反馈、数据四个环节，均为传统规则程序无法低成本实现的能力：

### 1. 输入层：非结构化信息转结构化计划
解析自然语言医嘱、药品图片OCR结果、手写处方等非标准化内容，自动提取药品名称、服药时间、剂量、服用要求，生成设备可执行的结构化计划，降低子女录入成本。
> **边界**：仅做信息提取与格式转换，不做用药对症判断、不推荐治疗方案。

### 2. 校验层：语义级安全拦截
结合药品常规使用常识，对解析出的剂量、频次做合理性校验，超出常规范围时阻断计划下发，并用自然语言说明异常点与常规参考范围，引导人工核对。
> **边界**：仅做常识级异常提示，最终确认权归子女所有，不做医疗判定。

### 3. 反馈层：状态信号转自然语言告警
将硬件输出的超时未取、重量异常等原始状态码，结合药品类型、时间、历史行为，转化为带上下文、有明确行动建议的自然语言提醒，降低子女信息判断成本。
> **边界**：仅做状态转译与行动建议，不涉及医疗判断。

### 4. 数据层：日志数据转规律总结
对一周零散的服药打卡日志做规律识别，输出精简的自然语言总结，明确漏服时段、变化趋势等隐性信息，替代人工数据梳理。
> **边界**：仅做客观趋势总结，不提供医疗建议。

### 5. 交互层：统一AI看护顾问入口
作为全链路能力的对话式交互入口，整合长辈健康档案、用药计划、传感器数据、设备状态信息，支持通过自然语言提问，查询用药规律、漏服原因、设备运行状态等内容；支持多位长辈档案切换，自动适配对应长辈的慢病情况、作息习惯与用药方案，输出针对性分析结果。
> **边界**：仅基于已同步的客观数据做信息解读，不提供疾病诊断、用药调整类医疗建议。

> **不使用LLM的环节**：传感器取药行为判定（时序规则即可实现，成本更低、稳定性更高）、常规语音播报（固定文本TTS即可）。

## 六、AI Coding原型Demo说明

### （一）技术实现
使用模型：Gemini Pro、豆包 2.1 Turbo，耗时3.5小时。单文件HTML网页，基于React 18 + Tailwind CSS开发，所有数据与AI能力均为前端Mock实现，无后端依赖，双击即可运行。

### （二）布局结构
桌面端左右分栏：
* **左侧60%**：子女端App控制台，为App化页面结构，包含3个核心页面：
  1. 监控主页（默认页）：展示今日服药进度、本周趋势概览、异常告警卡片
  2. 药方编辑页：提供慢病预设方案、自然语言/图片解析入口、结构化表单编辑、安全校验提示
  3. 看护报告页：展示核心数据指标与自然语言趋势总结
  * *右下角悬浮AI对话助手入口，支持自由提问用药相关问题*
* **右侧40%**：物理药箱模拟区，包含药仓状态图示与模拟操作控制台

### （三）硬件逻辑
1. **串行引导取药**：同一时间仅点亮1个药仓，当前药仓取药完成后自动点亮下一个，全部取药完成后统一播报结束，避免多药同时亮灯造成混淆
2. **误碰容错机制**：检测到取药后重量快速回弹，判定为误碰/放回，不更新服药状态、不触发完成记录，继续等待取药
3. **离线兜底逻辑**：设备断网时，本地时钟、声光提醒、取药判定正常运行，操作记录本地缓存；网络恢复后自动批量同步所有数据
4. **超时告警逻辑**：到点后超时未取药，药仓红灯闪烁，同步触发子女端自然语言告警# --demo
